# Decision Table Lab

デシジョンテーブル技法の練習問題2問と本番問題1問を、ブラウザ上で解答・採点できる静的Webアプリです。元データは `デシジョンテーブル課題_rev3.00` のCSV（rev3.00）です。

## 主な機能

- `T / F / − / X / N/A` をクリック入力するデシジョンテーブル
- 全組み合わせ表（最小化前）の自動採点
- 列順が異なる正解も受け付ける最小化表の意味的な採点
- N/A、最小化、選択式カバレッジ、4択の理解度チェック
- ブラウザの `localStorage` による入力と完了状況の自動保存
- PC・タブレット・スマートフォン対応

## ローカル実行

```bash
npm start
```

`http://localhost:4173/` を開きます。ビルドや依存パッケージのインストールは不要です。

## 検証

```bash
npm test
```

## 公開

静的ファイルだけで構成されているため、GitHub Pagesではリポジトリのルートを公開元に指定できます。解答データと採点処理はブラウザへ配信されるため、試験監督が必要な秘匿試験用途ではなく、学習・自己採点用途を想定しています。
