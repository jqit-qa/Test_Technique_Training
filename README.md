# Test Technique Training

QA事業部向けの、ブラウザで学べるテスト設計技法トレーニングです。

| 技法 | ディレクトリ |
| --- | --- |
| デシジョンテーブル | `decision-table/` |
| 境界値分析 | `boundary-value-analysis/` |
| 状態遷移テスト | `state-transition-testing/` |
| 同値分割法 | `equivalence-partitioning/` |
| ペアワイズテスト | `pairwise-testing/` |

各アプリは依存パッケージなしの静的Webアプリです。各ディレクトリで `npm test` を実行すると検証できます。GitHub Pagesではリポジトリのルートを公開元に設定します。
